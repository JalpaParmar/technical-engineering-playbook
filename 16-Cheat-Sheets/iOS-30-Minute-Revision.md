# iOS — 30-Minute Revision

## 0–5 min: Language & memory
Value vs reference semantics; optionals; protocols; ARC; strong/weak/unowned; closure capture.

## 5–10 min: UI/state
UIKit lifecycle; SwiftUI declarative state; ownership; navigation; accessibility; incremental interoperability.

## 10–15 min: Concurrency
async/await; actors; main actor; cancellation; structured concurrency; stale-result races.

## 15–20 min: Data
URLSession; auth refresh; retries/idempotency; caching/source of truth; persistence/migrations; offline sync.

## 20–25 min: Quality
XCTest; dependency seams; crash analysis; leaks; profiling; launch/render/main-thread performance.

## 25–30 min: Architecture & release
MVVM/Clean trade-offs; modularization; feature flags; API compatibility; signing/TestFlight/App Store; observability/hotfix.

## Speak these aloud
1. How would I modernize Objective-C incrementally?
2. How would I prevent a token-refresh storm?
3. How would I debug a leak?
4. How would I design offline booking?
5. What would I check before production rollout?
