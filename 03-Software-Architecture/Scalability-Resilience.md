# Scalability & Resilience

Scale dimensions include users, requests, data, read/write ratio, geography and burstiness.

Techniques: caching, horizontal scaling, partitioning, async work, batching, replicas, CDN and queues—each has costs.

Resilience: timeouts, bounded retries, circuit breaking, isolation/bulkheads, rate limiting, load shedding, graceful degradation and failover.

Start with measured demand and explicit growth assumptions. Identify the constrained resource before scaling everything.
