# Architecture Review Checklist

- [ ] functional/nonfunctional requirements clear
- [ ] scale assumptions explicit
- [ ] constraints/compliance known
- [ ] ownership/team boundaries understood
- [ ] component/data ownership clear
- [ ] consistency requirements explicit
- [ ] failure modes considered
- [ ] security/trust boundaries defined
- [ ] compatibility/evolution considered
- [ ] deployment/observability designed
- [ ] capacity/scaling path credible
- [ ] recovery/mitigation understood
- [ ] alternatives/trade-offs documented
- [ ] ADR recorded if consequential
