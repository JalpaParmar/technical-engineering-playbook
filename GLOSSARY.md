# Glossary

A growing quick-reference glossary. Detailed explanations belong in their canonical topic pages.

- **ADR — Architecture Decision Record:** concise record of an important architecture decision, context, alternatives and consequences.
- **API — Application Programming Interface:** contract through which software components communicate.
- **CI/CD — Continuous Integration / Continuous Delivery or Deployment:** practices that automate integration, validation and software delivery.
- **DI — Dependency Injection:** supplying dependencies from outside a component to reduce coupling and improve testability.
- **Idempotency:** property where repeating an operation has the same intended effect as performing it once.
- **JWT — JSON Web Token:** compact token format commonly used to carry signed claims; its use does not by itself guarantee secure authentication.
- **LLM — Large Language Model:** model trained on large-scale data to process and generate language and related representations.
- **MCP — Model Context Protocol:** protocol for connecting AI applications with tools and contextual data sources.
- **MVC — Model–View–Controller:** separation of model, presentation and control responsibilities.
- **MVI — Model–View–Intent:** unidirectional-state architecture pattern commonly used for predictable UI state.
- **MVVM — Model–View–ViewModel:** presentation architecture separating view logic from UI through a ViewModel.
- **Observability:** ability to understand system behavior through signals such as logs, metrics and traces.
- **RAG — Retrieval-Augmented Generation:** grounding model generation with retrieved external information.
- **RCA — Root Cause Analysis:** structured investigation into why an incident occurred and how recurrence can be reduced.
- **REST — Representational State Transfer:** architectural style commonly used for resource-oriented HTTP APIs.
- **TPM — Technical Project Manager / Technical Program Manager:** meaning depends on organizational context; this repository explicitly states which role is intended.
