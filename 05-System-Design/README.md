# System Design — Strong Track

## Framework
1. clarify functional requirements;
2. identify nonfunctional requirements;
3. state scale assumptions;
4. define APIs/data ownership;
5. sketch high-level architecture;
6. reason about consistency/failure/security;
7. add caching/queues/scaling only where justified;
8. design observability/operations;
9. explain trade-offs and evolution.
