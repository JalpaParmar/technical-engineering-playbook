# System Design Hands-On Exercises

For each exercise, spend 30–45 minutes: requirements → assumptions → API/data → architecture → failure/security → scaling → observability → trade-offs.

1. URL shortener
2. File upload and processing
3. Appointment booking
4. Payment processing
5. Notification service
6. Chat
7. Multi-tenant SaaS reporting
8. Mobile offline synchronization backend

After each design answer:
- What is the strongest consistency invariant?
- What fails partially?
- Where can duplicates occur?
- What becomes the first bottleneck?
- What would you postpone until evidence demands it?
