## Depth intent
iOS and mobile architecture receive the deepest treatment because they form the primary mobile engineering foundation. Android is built to strong working/architecture depth without inventing hands-on experience.

## Study method
**Learn → explain → apply → troubleshoot.** Read a concept, answer Q&A aloud, work through an exercise/scenario, then explain the trade-off without notes.

## Quality rules
Platform/version-sensitive details must be verified against current official documentation before production use. Examples are educational unless explicitly supported as real experience. Architecture recommendations are contextual, not universal rules.
