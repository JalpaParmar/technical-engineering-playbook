# Version-Sensitive Topics

Before production implementation, verify current official documentation for fast-changing areas including:

- iOS/Swift/SwiftUI platform APIs and App Store requirements;
- Android/Kotlin/Compose/Jetpack SDK and Play requirements;
- Firebase SDK/services;
- Azure service features, limits, identity and pricing;
- GitHub Actions/Azure DevOps features and security controls;
- OAuth/OIDC provider guidance;
- AI model/tool capabilities, context limits, pricing and product features;
- MCP/tooling implementations;
- third-party payment SDK/compliance requirements.

The playbook emphasizes durable engineering concepts; exact APIs, policies, limits and pricing can change.
