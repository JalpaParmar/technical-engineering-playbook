# Dependencies & API Readiness

## Dependency register
Dependency, owner, needed-by date, contract/deliverable, current confidence, fallback, impact and escalation trigger.

## API dependency
Freeze contract/examples early enough for parallel work. Mocks can reduce idle time but do not prove real integration.

## Critical path
Not every dependency is schedule-critical. Identify which unresolved dependency moves the delivery date or blocks validation.

## Escalation
Escalate with evidence and options: impact, latest needed date, owner, alternatives and decision required—not merely “team is delayed.”
