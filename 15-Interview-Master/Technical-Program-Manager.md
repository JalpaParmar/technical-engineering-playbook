# Technical Program Manager — Interview Pack

## Program lens
Coordinate multiple teams/workstreams around outcomes, architecture/dependency boundaries, milestones, risks, operating metrics and executive decisions.

## Questions to prepare
How do you manage cross-team dependencies? How do you expose critical path? How do you handle architecture disagreement? How do you govern API compatibility? How do you report risk without noise? How do you connect engineering health to program outcomes?

## Communication
Executives need impact, confidence, options and decision. Engineering teams need contracts, owners, technical constraints and integration milestones.
