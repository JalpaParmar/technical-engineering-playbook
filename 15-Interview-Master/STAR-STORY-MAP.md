# STAR Story Map

Create this from **real experience only**.

| Story | Can answer |
|---|---|
| Major production incident | incident, leadership, pressure, RCA, communication |
| Critical dependency delay | planning, escalation, API/mobile coordination, deadline |
| Large release | planning, quality, stakeholders, risk |
| Architecture/technical decision | technical depth, conflict, trade-offs |
| Automation improvement | AI/automation, efficiency, transformation |
| Scope change | change management, stakeholder negotiation |
| Quality problem | metrics, QA strategy, release decision |
| Team conflict/mentoring | leadership, communication |
| Legacy modernization | architecture, migration, risk |
| Multi-team initiative | program management, dependencies, governance |

## Story template
Situation (brief) → responsibility → 2–4 specific actions → measurable/observable result → lesson.

Do not invent metrics. Use qualitative outcomes when exact figures are unavailable.
