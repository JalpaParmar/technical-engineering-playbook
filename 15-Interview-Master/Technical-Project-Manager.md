# Technical Project Manager — Interview Pack

## Positioning
Bridge business outcomes and engineering execution with enough technical depth to challenge architecture, APIs, mobile/cloud delivery, quality, risk and release readiness.

## Answer framework
**Context → risk/problem → action/decision → technical collaboration → result/validation.**

## High-value scenarios
- API dependency delayed: contract/mocks, parallel work, integration milestone, escalation.
- Scope change: impact/options/approval/rebaseline.
- Production incident: stabilize, evidence, communication, recovery, RCA.
- Architecture disagreement: constraints/evidence/trade-offs/decision owner.
- Release risk: quality + dependencies + observability + mitigation, not bug count alone.

Use real experience only; do not invent metrics/results.
