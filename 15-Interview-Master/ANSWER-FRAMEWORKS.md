# Easy-to-Remember Answer Frameworks

## Technical concept — DTEV
**Define → Trade-off → Example → Validate**

## Scenario — CAVED
**Clarify → Assess → Verify evidence → Execute → Demonstrate recovery**

## PM problem — IODA
**Impact → Options → Decision → Action**

## Incident — ISICV
**Impact → Stabilize → Investigate → Communicate → Validate**

## Requirement — PACE
**Problem → Acceptance → Constraints → Edge cases**

## AI feature — OMEGA
**Outcome → Model/workflow → Evaluation → Guardrails → Adoption/monitoring**

These are memory aids, not rigid scripts.
