# Software Architect — Interview Pack

## Core themes
Architecture is constraint/trade-off management, not technology collection.

Prepare to discuss:
- monolith vs modular monolith vs microservices;
- distributed failure and idempotency;
- data consistency;
- event-driven systems;
- scalability/resilience;
- security boundaries;
- observability;
- ADRs;
- modernization;
- system design.

## Answer pattern
**Requirements → constraints → options → decision → trade-offs → validation.**

## Lead questions
- When would you reject microservices?
- How do you evolve an API with old clients?
- How do you handle a dual-write problem?
- How do you prevent retry storms?
- How do you know an architecture decision worked?
