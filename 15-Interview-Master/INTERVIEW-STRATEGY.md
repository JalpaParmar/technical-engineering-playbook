# Interview Strategy

## Objective
Demonstrate judgment, not memorized terminology.

## Answer lengths
- **Screening:** 30–60 seconds; direct answer + one example.
- **Manager round:** 1–2 minutes; context, action, trade-off, result.
- **Technical/architect round:** start concise, then deepen when probed.
- **Leadership round:** outcome, decision framework, risk, stakeholders and evidence.

## Technical answer pattern
**Definition/position → when/why → trade-off → example → validation.**

## Scenario answer pattern
**Clarify → impact/evidence → options → action/decision → validation → communication.**

## Experience rule
Use real experience only. If a question covers technology you understand but have not personally implemented deeply, say so naturally and explain how you would review/lead it.

## AI-era differentiator
Explain where AI accelerates work **and** where human validation remains mandatory.
