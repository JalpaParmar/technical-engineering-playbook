# Software Engineering Hands-On Exercises

1. Refactor a class with mixed networking, persistence and presentation responsibilities; explain boundaries, not just file count.
2. Replace a conditional-heavy pricing algorithm with Strategy only if variation justifies it; compare complexity before/after.
3. Create a logical race where stale async work overwrites current state; fix and test it.
4. Review a deliberately risky PR for correctness, security, retries, tests and observability.
5. Take a legacy function without tests, add characterization tests, then refactor in small steps.
6. Create a technical-debt entry tied to measurable delivery/incident impact and propose incremental treatment.
