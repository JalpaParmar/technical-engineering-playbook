# Senior Software Engineering Q&A

**What does SOLID achieve?** Heuristics that can reduce coupling and improve changeability/testability when applied to real variation; not rigid rules.

**Why DI?** Explicit replaceable dependencies improve separation/testing. It becomes harmful when trivial dependencies gain unnecessary indirection.

**Legacy code?** Understand behavior/risk, add characterization tests around critical paths, refactor incrementally at change boundaries.

**Good code review?** Correctness/risk first: behavior, security, failure/concurrency, architecture, tests and observability.

**Technical debt?** Classify and quantify impact, prioritize against product risk/value, remediate incrementally where practical.
