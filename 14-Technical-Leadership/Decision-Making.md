# Technical Decision-Making

## Framework
Problem → constraints → options → evidence → trade-offs → decision owner → validation/revisit trigger.

Separate reversible from expensive/irreversible decisions. Time-box experiments when evidence can cheaply reduce uncertainty.

## Avoid
HiPPO-only decisions, architecture by fashion, endless consensus, and undocumented assumptions.

## ADR
Use an Architecture Decision Record for consequential choices; do not create one for every code-level preference.
