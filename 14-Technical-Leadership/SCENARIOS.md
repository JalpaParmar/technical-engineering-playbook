# Technical Leadership Scenarios

## API team delayed
Identify blocking contracts/endpoints, agree mocks, parallelize safe work, define integration milestone and escalate critical-path impact.

## Senior engineers disagree
Document decision and constraints, compare evidence/trade-offs, prototype uncertain point if economical, then use decision owner.

## Release has 8 medium defects
Assess affected journeys, likelihood/impact, workaround, regression confidence and release objective. Severity labels alone do not decide go/no-go.

## Architecture rewrite proposed
Ask measurable pain, migration/test strategy, opportunity cost and incremental alternatives.

## Incident with executive pressure
Maintain factual communication cadence. Do not invent ETA/root cause. Give current impact, mitigation, investigation and next update time.
