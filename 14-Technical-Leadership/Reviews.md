# Architecture & Code Reviews

## Architecture review
Requirements/NFRs, boundaries/data ownership, failure/consistency, security, testability, operability, compatibility, rollout and trade-offs.

## Code review
Correctness/business invariants → security/data → concurrency/failure → architecture → tests → observability → readability.

## Leadership behavior
Challenge the design, not the person. Ask evidence-based questions and distinguish blocking correctness/risk concerns from preferences.
