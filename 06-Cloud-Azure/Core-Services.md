# Core Azure Services

**App Service:** managed web/API hosting; review runtime, scaling, networking, deployment and observability.

**Azure Functions:** event-driven/serverless compute; consider runtime limits, idempotency and downstream pressure.

**Storage:** blob/queue/table/file capabilities for different access patterns.

**Azure SQL:** managed relational database; review capacity, HA/backup, networking, identity and queries.

**Key Vault:** secrets/keys/certificates with controlled access.

**Azure Monitor/Application Insights:** telemetry, metrics, logs/traces and alerting.
