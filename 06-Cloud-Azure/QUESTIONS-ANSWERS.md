# Azure Q&A

**Functions vs App Service?** Functions suit event-driven/serverless workloads; App Service suits continuously hosted web/API workloads. Decide from workload/scaling/operations.

**Why Key Vault?** Controlled secret/key/certificate management; combine with workload identity where possible.

**TPM Azure knowledge?** Architecture, environments, identity/secrets, dependencies, scaling, observability, resilience, cost and ownership.

**Cloud cost?** Identify drivers, compare planned/actual, right-size/remove waste and connect spend to service/business value.
