# Quality Metrics

Useful signals include escaped defects, defect leakage, reopen rate, crash/ANR-free behavior, regression rate, flaky-test rate, failed deployment/change failure and time to detect/recover.

Metrics need consistent definitions and context. A falling bug count can mean better quality—or reduced reporting.

## TPM use
Combine leading signals (test health, risk coverage, code/release changes) with lagging production outcomes. Avoid ranking individuals using defect counts.
