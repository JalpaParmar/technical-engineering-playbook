## Learning paths
**Mobile Developer / iOS Refresh:** Start Here → Mobile/iOS → Mobile Architecture → Testing → Debugging → DevOps → Security.

**Mobile Tech Lead:** Mobile → Architecture → System Design → Technical Leadership → Incidents → Interview Master.

**Technical Project/Program Manager:** Start Here → Software Architecture → Backend/API → Cloud → DevOps → System Design → Requirements → Technical Leadership.

**AI-Enabled TPM:** TPM path → AI Engineering → AI-Assisted Development → AI-related interview material.

## Interview paths
- **30 minutes:** Cheat Sheets → Interview Master → selected Checklists.
- **3 days:** Start Here → target-role technical areas → scenarios/playbooks → Interview Master.
- **Deep preparation:** follow the relevant learning path and work through examples, trade-offs and troubleshooting.

## Content model
Substantial topics may include a relevant subset of: concepts, Q&A, examples, scenarios, troubleshooting, best practices, checklists, playbooks and cheat sheets. We deliberately avoid creating every file type for every topic.
