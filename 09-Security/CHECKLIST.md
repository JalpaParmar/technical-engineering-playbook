# Security Review Checklist

- [ ] sensitive assets/data identified
- [ ] trust boundaries mapped
- [ ] authentication appropriate
- [ ] resource/action authorization enforced server-side
- [ ] tenant isolation reviewed
- [ ] input validation/error handling reviewed
- [ ] secrets absent from source/logs
- [ ] least privilege applied
- [ ] dependency/supply-chain risks reviewed
- [ ] sensitive telemetry minimized
- [ ] abuse/rate-limit needs considered
- [ ] security monitoring/incident owner defined
