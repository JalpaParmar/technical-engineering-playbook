# Security Q&A

**Authentication vs authorization?** Identity vs permission to perform an action on a resource.

**Why server authorization if app hides the feature?** Clients can be modified; trusted backend boundaries must enforce policy.

**Least privilege?** Give principals only permissions required for their task/scope, reducing blast radius.

**Threat model?** Structured reasoning about assets, trust boundaries, threats and controls before incidents expose gaps.

**Vulnerability scanner result?** Evidence requiring triage/context; severity, exposure and compensating controls affect remediation priority.
