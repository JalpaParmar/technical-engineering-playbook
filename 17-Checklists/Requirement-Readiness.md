# Requirement Readiness Checklist

- [ ] user/problem/outcome clear
- [ ] current vs desired behavior clear
- [ ] scope/out-of-scope explicit
- [ ] business rules sourced
- [ ] acceptance criteria testable
- [ ] permissions/errors/edge cases considered
- [ ] NFRs identified
- [ ] dependencies/owners known
- [ ] assumptions/open questions visible
- [ ] release/validation implications understood
