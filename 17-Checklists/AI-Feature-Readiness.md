# AI Feature Readiness Checklist

- [ ] user outcome/failure cost defined
- [ ] model-suitable vs deterministic work separated
- [ ] data authorization/privacy reviewed
- [ ] prompt/context version controlled
- [ ] structured output validated
- [ ] retrieval quality evaluated if RAG
- [ ] prompt-injection/tool risks reviewed
- [ ] human approval for consequential actions
- [ ] representative eval suite passes
- [ ] latency/cost budget measured
- [ ] production telemetry/feedback ready
- [ ] fallback/degraded behavior defined
