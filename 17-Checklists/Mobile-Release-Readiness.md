# Mobile Release Readiness Checklist

## Scope
- [ ] release scope and acceptance criteria clear
- [ ] known limitations documented
- [ ] high-risk changes identified

## Mobile builds
- [ ] versions/build numbers correct
- [ ] production configuration/signing verified
- [ ] feature flags correct
- [ ] permissions/privacy-sensitive changes reviewed

## Backend
- [ ] required APIs deployed/compatible
- [ ] backward compatibility understood
- [ ] migrations/configuration complete
- [ ] third-party dependencies checked

## Quality
- [ ] critical regression complete
- [ ] upgrade path tested
- [ ] supported device/OS coverage risk-based
- [ ] offline/error/auth-expiry paths considered
- [ ] accessibility/localization risk reviewed

## Operations
- [ ] crash/ANR monitoring ready
- [ ] analytics/critical telemetry ready
- [ ] staged/phased rollout decision made
- [ ] mitigation/feature-disable/hotfix path clear
- [ ] owners/stakeholders know release risks

## Store
- [ ] current App Store/Play requirements verified
- [ ] release notes/metadata ready
- [ ] review timing risk considered
