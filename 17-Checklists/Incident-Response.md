# Incident Response Checklist

- [ ] impact/severity bounded
- [ ] incident owner established
- [ ] data/user safety considered first
- [ ] recent release/config changes captured
- [ ] evidence preserved
- [ ] facts separated from hypotheses
- [ ] safe mitigation options assessed
- [ ] stakeholder cadence established
- [ ] recovery validated with production signals
- [ ] timeline/decision log retained
- [ ] RCA/preventive actions assigned
