# Production Readiness Checklist

- [ ] scope/owners clear
- [ ] architecture risks accepted
- [ ] CI/tests/security gates passed
- [ ] production config/secrets verified
- [ ] data migrations rehearsed
- [ ] dependencies ready
- [ ] capacity/scaling reviewed
- [ ] dashboards/alerts/runbooks ready
- [ ] rollout strategy defined
- [ ] rollback/mitigation defined
- [ ] stakeholder/support communication ready
- [ ] post-release validation owner assigned
