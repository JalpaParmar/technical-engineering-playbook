# Authoring Templates

Use only the sections that add value. These are quality scaffolds, not mandatory boilerplate.

## Q&A
```markdown
### Question
**Short interview answer:** ...

**Deep dive:** ...

**Example:** ...

**Trade-offs:** ...

**Follow-up questions:**
- ...
```

## Checklist
```markdown
# <Topic> Checklist
## Before
- [ ] ...
## During
- [ ] ...
## Validation
- [ ] ...
## Rollback / escalation
- [ ] ...
```

## Playbook
```markdown
# <Situation> Playbook
## Trigger
## Assess impact
## Evidence to gather
## Stabilize
## Decision points
## Execute
## Validate
## Communicate
## Monitor
## Prevent recurrence
## Common mistakes
## Escalation criteria
```

## Example / Scenario
```markdown
# <Scenario>
**Type:** Illustrative example
## Problem
## Constraints / assumptions
## Approach
## Implementation or design
## Why it works
## Alternatives
## Trade-offs
## Failure modes
## Validation
## Interview follow-ups
```

## Cheat Sheet
```markdown
# <Topic> — Quick Revision
## Mental model
## Key concepts
## Decisions / trade-offs
## Common mistakes
## 5 questions to test yourself
## Links to deeper material
```
