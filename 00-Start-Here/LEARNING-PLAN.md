# How to Use This Repository Without Overwhelm

You do **not** need to memorize 233 files.

## 30 minutes
Use [Master Revision](../16-Cheat-Sheets/Master-30-Minute.md).

## Interview tomorrow
Use [Interview Strategy](../15-Interview-Master/INTERVIEW-STRATEGY.md), the target role pack, [Master Scenarios](../15-Interview-Master/MASTER-SCENARIOS.md), then your real STAR stories.

## One week
Day 1 Mobile → Day 2 Architecture/System Design → Day 3 Backend/Azure/DevOps → Day 4 Quality/Security/Incidents → Day 5 AI → Day 6 Requirements/Leadership → Day 7 mock interview.

## Ongoing
Choose one real work/interview gap, study the canonical page, do one exercise, explain it aloud, then use the checklist/playbook.

## Learning loop
**Read → explain without notes → apply to scenario → identify gap → revisit.**

The repository is a reference system, not a book that must be read front-to-back.
