# AI for Legacy Code & Modernization

AI can accelerate code mapping, dependency discovery, characterization-test suggestions and incremental migration plans.

## Safe flow
Inventory → map behavior/dependencies → identify seams → protect with tests → migrate small boundary → diff/review → regression → measure.

## Examples
Objective-C→Swift analysis, UIKit→SwiftUI boundary planning, Java→Kotlin planning, callback→structured concurrency analysis.

Never accept bulk rewrites solely because generated code compiles.
