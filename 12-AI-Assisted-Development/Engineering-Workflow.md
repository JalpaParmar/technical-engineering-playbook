# AI-Assisted Engineering Workflow

```text
Requirement → Human clarification → AI analysis → Plan/architecture
→ Implementation → AI review/tests → Automated checks
→ Human review → PR → Runtime validation
```

## Good uses
Codebase explanation, search, scaffolding, test ideas, refactoring options, migration planning, documentation and review assistance.

## Human-owned
Requirements, architecture trade-offs, security/privacy, production actions, acceptance of generated code and final validation.

## Rule
Ask AI for evidence: files/functions/tests/diffs. “It looks correct” is not verification.
