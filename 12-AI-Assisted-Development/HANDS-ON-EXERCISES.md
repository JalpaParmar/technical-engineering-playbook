# AI-Assisted Development Exercises

1. Ask AI to explain an unfamiliar module and verify every cited file/function.
2. Generate tests for a retry/idempotency component; identify weak assertions.
3. Plan Objective-C→Swift migration without rewriting the whole feature.
4. Review a deliberately unsafe generated API client.
5. Use AI on sanitized incident evidence and reject unsupported hypotheses.
6. Compare two tools on the same bounded refactor using quality/time/rework criteria.
