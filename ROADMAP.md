# Roadmap

This repository is built in gated phases so depth is not sacrificed for file count.

## Phase 1 — Foundation ✅
Repository navigation, standards, templates, learning/interview paths, glossary and quality rules.

## Phase 2 — Deep Mobile Engineering
**iOS first**, then Android and Mobile Architecture. Deep concepts, practical code, Q&A, troubleshooting, modernization, architecture trade-offs and release concerns.

## Phase 3 — Software Engineering + Architecture + System Design
Senior engineering foundations, architecture decision-making and worked system designs.

## Phase 4 — Backend/API + Azure + DevOps/CI-CD
Integration architecture, reference API, cloud decision knowledge and delivery/release pipelines.

## Phase 5 — Testing + Security + Debugging/Incidents
Quality strategy, defensive security and evidence-driven incident engineering.

## Phase 6 — AI Engineering + AI-Assisted Development
LLM/product architecture plus responsible AI-assisted engineering workflows.

## Phase 7 — Requirement Engineering + Technical Leadership
Requirements-to-delivery flow, reviews, planning, technical debt, mentoring, risk and stakeholder communication.

## Phase 8 — Consolidation
High-value Q&A, scenarios, checklists, playbooks and cheat sheets. Prefer canonical links over duplication.

## Phase 9 — Interview Master
Role-specific packs: Mobile Tech Lead, iOS Tech Lead, TPM, Technical Program Manager, Software Architect, AI Project Manager, System Design and Cloud/DevOps.

## Phase 10 — Repository Audit
Accuracy, current terminology, internal links, duplication, code quality, navigation, mobile readability and coverage.

## Gate rule
A phase does **not** start automatically. Complete and review the current phase first.
