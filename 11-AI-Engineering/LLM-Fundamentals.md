# LLM Fundamentals

Large language models generate outputs from learned statistical patterns conditioned on input/context. They do not provide a built-in guarantee of truth.

## Concepts
Tokens/context window, system/developer/user instructions, sampling, latency, model capability, multimodal input and tool use.

## Engineering implication
Treat model output as untrusted probabilistic output. Validation strength should increase with business/safety impact.

## Model selection
Consider task quality, latency, cost, context size, modality, tool support, privacy/data policy and evaluation results—not simply “largest model.”
