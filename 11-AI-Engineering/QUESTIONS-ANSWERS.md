# AI Engineering Q&A

**RAG vs fine-tuning?** RAG supplies external/current knowledge at runtime; fine-tuning changes model behavior/weights for suitable tasks. They solve different problems and can coexist.

**Embedding?** Numeric representation used for semantic similarity; not a truth or permission mechanism.

**Agent vs workflow?** Use an agent when dynamic iterative decisions/tool use add value; prefer deterministic workflow for predictable steps.

**Hallucination?** Unsupported/generated content presented as if valid. Reduce with grounding, constraints, validation and appropriate human review; do not promise elimination.

**How evaluate AI?** Representative task set + task-specific rubric/metrics + regression evaluation + production monitoring.

**MCP?** Standard protocol for connecting AI applications to tools/context; permissions and trust boundaries still require design.
